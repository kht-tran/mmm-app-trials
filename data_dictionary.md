# Data Dictionary — Marketing Mix Analysis of App Trials

Daily-level data, one row per date.

## Target Variable

| Variable | Description |
|---|---|
| `Date` | Date of each observation (daily frequency) |
| `Trial` | Number of daily app trials (i.e., how many users downloaded/activated a trial of the app that day) |

## Online Paid Media

### CPC/CPM campaigns
Digital display/banner ads bought on a Cost-Per-Click or Cost-Per-Mille (thousand impressions) basis.

| Variable | Description |
|---|---|
| `CPC/CPM_clic` | Number of clicks generated by CPC/CPM campaigns |
| `CPC/CPM_spend` | Money spent on CPC/CPM campaigns |

### CPD campaigns
CPD = Cost Per Download.

| Variable | Description |
|---|---|
| `CPD_CLIC` | Clicks from CPD campaigns |
| `CPD_spend` | Spend on CPD campaigns |

### Search (all)
Aggregate of always-on and broad search below.

| Variable | Description | Relationship |
|---|---|---|
| `CLIC_SEARCH` | Total clicks from all paid search (Google/Bing ads) | `CLIC_SEARCH = clic_search_alwayson + clic_search_broad` |
| `SEARCH_spend` | Total spend on all paid search | `SEARCH_spend = search_alwayson_spend + search_broad_spend` |

#### Search — Always On
Campaigns running continuously, not tied to a specific promotion.

| Variable | Description |
|---|---|
| `clic_search_alwayson` | Clicks from always-on search campaigns |
| `search_alwayson_spend` | Spend on always-on search |

#### Search — Broad
Campaigns using broad keyword matching (wider audience targeting).

| Variable | Description |
|---|---|
| `clic_search_broad` | Clicks from broad-match search campaigns |
| `search_broad_spend` | Spend on broad search |

## Offline Media

### TV
GRP = Gross Rating Point, a standard TV advertising pressure metric (reach × frequency).

| Variable | Description | Relationship |
|---|---|---|
| `TV_Grp_Mediaset_Premium_Sky` | GRPs delivered on paid/commercial TV channels (Mediaset, Premium, Sky) | — |
| `TV_Grp_Rai` | Total GRPs on RAI (public TV) | `TV_Grp_Rai = TV_Grp_Rai3_OnAir1 + OnAir2 + OnAir3 + OnAir4` |
| `TV_Grp_Rai3_OnAir1` … `OnAir4` | GRPs split by creative flight — each "OnAir" corresponds to a different TV creative/ad version airing on Rai3; useful for testing whether different creatives perform differently | — |
| `tot_tv` | Total TV GRPs across all channels | `tot_tv = TV_Grp_Mediaset_Premium_Sky + TV_Grp_Rai` |

### Radio

| Variable | Description |
|---|---|
| `RADIO_Grp` | GRPs delivered via radio advertising |

## Other

| Variable | Description |
|---|---|
| `WEB_MENTIONS` | Organic mentions of the brand/product on the web (news, blogs, forums); captures earned media / PR effects |
| `DUMMY_SEARCH` | Binary (0/1) flag, likely marking periods when a special search campaign or promotion was active (or a structural break in the data) |

## Notes
**Exposure vs. spend**: 
- For online channels, "clicks" (`_clic`) serve as the exposure metric and `_spend` as the cost metric.
- For offline channels (TV, Radio), GRPs are used as a proxy for both exposure and spend, since currency-denominated spend was not available.
